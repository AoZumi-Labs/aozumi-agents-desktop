# AOZUMI Agents for Mac

Releases of the AOZUMI Agents desktop app. Coding agents run on your Mac, or in the cloud on [AOZUMI](https://aozumi.dev).

**[Download the latest release →](https://github.com/AoZumi-Labs/aozumi-agents-desktop/releases/latest)** (the `.dmg`)

- Needs an Apple Silicon Mac (M1 or later) on macOS 13 or newer.
- Installed apps update themselves from these releases. Settings → Updates shows when one is ready.
- Test builds aren't notarized by Apple yet, so the first open needs **Open Anyway** in System Settings → Privacy & Security.

This repository holds releases only; the app's source is private. AOZUMI Agents is licensed under the Apache License 2.0 (see `LICENSE` and `NOTICE`). It bundles git, licensed under the GNU GPL v2; each release attaches git's source as `git-source.tar.gz`.
